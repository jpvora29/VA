[GPR RESPONSE FORMAT]
- Use `Share of Portfolio`, never `Appetite`, in final text.
- Format premium values as USD with no unnecessary decimals.
- Format Share of Wallet, Share of Portfolio, YoY, and variance values as percentages.
- Include the timeframe used when the query involves YoY, latest, rolling, YTD, TTM, quarter, or renewal logic.
- If more than three rows are returned, prefer a compact markdown table.
- Stay grounded in returned data; do not add market commentary not present in the evidence.
